Termination State & Success Rate

How a run's frame trace becomes one termination reason, a counted infraction set, and a Success Rate — the exact chain, function by function.

frames (trace) -> termination.classify      ONE reason, the earliest event
               -> infractions_from_trace    counted contacts (fault-respecting)
               -> route.route_progress      monotone route completion
               -> termination.to_route_result   RouteResult, or None (excluded)
               -> RouteResult.success()     SR

Part I

Termination

Exactly one reason per episode, chosen by termination.classify. It answers "why did stepping stop" — never "what did the ego do wrong." Everything countable against the policy is an infraction (Part II).

1.3 Goal

scoring/route.py::at_goal: remaining route arc ≤ max(2.0 m, 1 % of total arc) and distance to the goal point < 10 m (COMPLETION_PCT_FOR_DONE = 99.0, GOAL_RADIUS_M = 10.0, GOAL_ARC_TOL_M = 2.0). Route completion is a monotone cursor along the logged ego path (route_progress). The live evaluator calls the same predicate over the same dense path (route_manager.py::goal_reached).

If the evaluator's metrics.json says goal_reached but the recompute disagrees, the report is honoured with goal_frame=None and a note (here).

1.4 Time budget

t_max = SAFETY_CEILING_S = 60.0 unless --t-max is passed. The rubric's "0.95-quantile human × 1.3, floor 10 s" (rubric/calibrate_tmax.py) is not used by this chain. Windows shorter than t_max get a scored window is … but t_max is … note.

Part II

Success Rate

One rule, for every scenario and every taxonomy leaf: completion plus a clean infraction set.

2.1 The rule

scoring/metrics.py::RouteResult.success — Bench2Drive merge_route_json.py L20-27, one rule for every scenario and every taxonomy leaf:

success  =  completed
            AND every infraction count is 0, except min_speed_infractions
            AND outside_route_lanes == 0

completed is termination.reason is GOAL_REACHED (to_route_result). Route completion percentage alone never grants success. SR over a set = success_rate, with an explicit denominator; excluded episodes (RouteResult is None) are outside it, never 0.

2.4 Not-at-fault contacts

contact_not_at_fault ends the episode (the world is no longer meaningful) but adds no infraction and is not policy-attributed. completed is False (the reason is not GOAL_REACHED), so SR is false for that run, with DS = route completion at the contact frame × whatever penalty the run had earned.
